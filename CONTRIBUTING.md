# Contributing

Small, auditable contributions are preferred. Useful contributions include:

- reproducing `python verify.py` on another platform;
- checking the figure build in a clean Python 3.12 environment;
- adapting the fate accounting to another ordered validator; and
- reporting a claim, citation, or manifest inconsistency.

Please include the operating system, Python version, exact command, observed
output, and the release or commit tested. Do not submit API keys, private logs,
or proprietary data.

Changes to evidence must preserve the original rows or document why a new
version is being released. Generated PDF figures must include their renderer,
source data, dependency lock, and a verification check.
