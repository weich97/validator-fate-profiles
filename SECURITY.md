# Security policy

This repository contains offline research evidence and verification scripts.
It does not require credentials or access to an external service.

## Supported version

Security and integrity fixes are applied to the latest tagged release.

## Reporting a problem

Please open a private security advisory in the GitHub repository for suspected
credential exposure, path disclosure, archive traversal, unsafe subprocess
handling, or integrity-check bypasses. Ordinary reproducibility problems can be
reported through a public issue.

Do not include a live credential or private dataset in an issue. Reproduce a
problem with a synthetic value and describe the affected file and command.
